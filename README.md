# Canc Shop - Система управления канцелярским магазином

## 📋 Описание проекта

**Canc Shop** - это современная система управления канцелярским магазином, разработанная на Python с использованием PyQt5. Проект включает в себя функциональность для авторизации, управления товарами, регистрации пользователей и многое другое.

## 🚀 Основные возможности

- **Современный интерфейс авторизации** с полупрозрачными элементами и градиентным дизайном
- **Система управления товарами** с возможностью добавления, редактирования и удаления
- **Регистрация пользователей** с валидацией данных
- **Управление сессиями** и безопасная авторизация
- **Красивый UI** с современными эффектами и анимациями

## 🛠 Технологии

- **Python 3.x**
- **PyQt5** - для создания графического интерфейса
- **SQLite** - для хранения данных
- **Qt Designer** - для создания UI файлов

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/xenon22313/Canc_shop.git
   cd Canc_shop
   ```

2. **Установите зависимости:**
   ```bash
   pip install PyQt5
   ```

3. **Запустите приложение:**
   ```bash
   python login.py
   ```

## 🔧 Разработка

### Создание UI файлов
UI файлы создаются в Qt Designer и сохраняются в папке `ui/`. Для компиляции UI файлов в Python код используйте:

```bash
pyuic5 -x ui/login.ui -o login_ui.py
```

### Структура базы данных
Проект использует SQLite для хранения данных пользователей и товаров.
